ALUMINIUM WINDOWS

Alu framed windows

Aluminium framed windows are durable, lightweight windows with slim frames made from aluminium, offering excellent weather resistance, low maintenance, and a sleek, modern aesthetic that allows for larger glass areas and more natural light.

Sliding/swing windows

An aluminium sliding window features sashes that glide horizontally along a track, offering space-saving ventilation and wider views. An aluminium swing window (also known as a casement or awning window) opens outwards or inwards on hinges, providing excellent ventilation and a tight seal when closed. Both utilize durable aluminium frames.

Top hung windows

Aluminium top hung windows are hinged at the top and open outwards from the bottom, allowing for ventilation even during rain while providing good weather protection and security.

Scissor push windows

Aluminium scissor push windows, often known as awning windows with scissor arm operators, are windows that are hinged at the top and push outwards from the bottom using a scissor-like arm mechanism. This design allows for ventilation while offering protection from rain and maintaining security.

Fixed windows
